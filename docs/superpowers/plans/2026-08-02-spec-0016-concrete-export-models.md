# Spec 0016 Concrete Export Models Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Freeze canonical DocumentBundle and RagDocument Pydantic contracts with strict graph/reference validation, generated JSON Schema, and representative round-trip fixtures.

**Architecture:** Keep all canonical DTOs in bochord.models.ocr and their public imports in bochord.models. Models validate persisted shape/invariants; DocumentExportService (Spec 0006) derives content and BundleLayoutService writes it. No document-specific semantic ontology is introduced.

**Tech Stack:** Python 3.13, Pydantic 2, pytest, stdlib json/pathlib.

**Sequence:** 5 of 5. Execute after Spec 0006.

---

## Global Constraints

- Implementers: only **Composer 2.5 Fast** (mechanical) or **Cursor Grok 4.5** (integration judgment). Reviewers: any appropriate model.
- Per task: implementer → spec review → same implementer fixes/re-review → code-quality review → same implementer fixes/re-review. Fresh whole-plan reviewer after Task 4.
- Before Python: source .venv/bin/activate. After Python edits: touched-file ruff, mypy, make napoleon-gate, focused pytest.
- Canonical shapes remain in bochord.models.ocr; do not split into a new “export framework.”
- Use JSON Schema generated by Pydantic; do not hand-maintain a duplicate schema.
- Preserve provisional region/note/table RAG vocabulary, but do not implement table chunks or target-domain entry/section/translation models.

## Existing Baseline

- DocumentBundle validates schema-version agreement, known source page count, unique ordered page ids/numbers.
- BundlePage validates unique local graph ids and parent/child/note-marker references.
- PreparedPage already binds image checksum, recipe, coordinate space, transforms, and units.
- RagDocument/RagChunk/StitchedChunk currently hold required fields but lack document-level cross-reference validation and frozen schema fixtures.

### Task 1: Tighten Bundle and Page Graph Contract Invariants

**Files:** Modify bochord/models/ocr.py; Modify tests/test_ocr_models.py.

- [ ] **Step 1: Write failing negative tests**

Cover:
- PreparedPage prepared_unit ids unique and each unit belongs to page/prepared page coordinate context;
- every graph box/polygon names one known page coordinate space, every non-empty LineRecord.baseline names an explicit baseline_coordinate_space_id, and no box/polygon/baseline silently uses an unknown space;
- every line listed by a region has that region_id, every span listed by a line has that line_id, and note listed by a region has that region_id;
- region reading_order_index values are positive/unique and line_order values are positive/unique within their parent region;
- every ObjectProvenance.source_page_id equals its owning BundlePage.page_id and its witness_ids/runner_ids resolve to witnesses owned by that page;
- PageOverlay/review fields remain external references, not a second embedded graph;
- document page ids stay unique and source page count remains exact.

Keep tests to observable validation errors; reuse fixture builders rather than duplicate full pages.

### Task 2: Validate RAG Document Referenceability

**Files:** Modify bochord/models/ocr.py; Modify tests/test_ocr_models.py.

- [ ] **Step 1: Write failing tests**

Assert RagDocument rejects:
- duplicate page-local chunk_id or stitched_chunk_id;
- chunk/stitch document_id unequal to parent document_id;
- page-local RagChunk page_ids other than exactly one page or empty source_object_ids;
- mismatch between page-local chunk page_ids and RetrievalProvenance.source_page_ids;
- stitched component_chunk_ids missing from page-local chunks;
- StitchedChunk page_ids other than at least two distinct ordered pages;
- mismatch between stitched page_ids and ordered distinct union of its component chunk provenance page ids.

Also prove valid region and footnote page-local chunks plus a cross-page stitched chunk round-trip.

- [ ] **Step 2: Verify RED**

- [ ] **Step 3: Implement direct validator**

Add RagDocument.validate_references. Require each RagChunk to represent exactly one page and its single provenance page; require each StitchedChunk to represent at least two distinct pages in component order and match the ordered distinct provenance-page union. Check ids/document ownership/component existence. Do not calculate text, infer trust, or look up DocumentBundle from this model.

## Final Review Focus

- Every reference/parent/coordinate/provenance invariant rejects malformed persisted data early.
- Generated JSON Schema and fixtures are exact contract evidence, not a handwritten duplicate.
- Export services conform to model contract without forcing a TEI or downstream ontology.

## Cost Stop

Stop after concrete bundle/RAG validation and contract snapshots. No table extraction, XML output, search integration, or semantic consumer models.
