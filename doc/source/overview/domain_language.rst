===============
Domain Language
===============

``bochord`` uses a shared glossary so architecture, implementation, review, and
operator workflows all refer to the same concepts.

Primary source:

- `CONTEXT.md <../../../CONTEXT.md>`_

What this glossary covers:

- source, prepared page, and prepared unit terminology
- page classes and preparation language
- page graph terms such as region, line, span, and note
- merge, provenance, confidence, and trust-state vocabulary
- export terms such as bundle JSON, RAG JSON, Markdown, and chunks

Operator guidance:

- prefer glossary terms over ad hoc synonyms in docs, code comments, and review
  notes
- when a new concept becomes stable and important, add it to ``CONTEXT.md``
  instead of redefining it locally in multiple docs

For the current canonical vocabulary, read:

- `bochord CONTEXT.md <../../../CONTEXT.md>`_
